THEORY VIDEOS
=============

Put one video per experiment in this folder. It plays at the top of that
experiment's Theory step. Name the files exactly like this:

  experiment-01.mp4   Data Pre-processing for Machine Learning
  experiment-02.mp4   Linear Regression
  experiment-03.mp4   Cross-Validation for Model Evaluation
  experiment-04.mp4   Logistic Regression for Binary Classification
  experiment-05.mp4   Principal Component Analysis (PCA)
  experiment-06.mp4   Support Vector Machine Classification
  experiment-07.mp4   K-Means Clustering
  experiment-08.mp4   Decision Tree Classification
  experiment-09.mp4   Random Forest Classification
  experiment-10.mp4   Artificial Neural Network using Perceptron Learning

Optional extras (same name, different ending):

  experiment-01.webm  used if there is no .mp4
  experiment-01.jpg   cover image shown before the video plays
  experiment-01.vtt   captions / subtitles

Until a video is added, the Theory step shows a "video coming soon" panel.
